About me

Python data analyst building GenAI systems.

I'm a Data Analyst and AI Engineer based in Chennai. I work as a Program Associate – Data Analyst at CEGIS Foundation, where I build Python data pipelines, predictive models and risk analytics on public procurement data.

My focus is applied GenAI and analytics: LLM applications with LangChain and retrieval-augmented generation (RAG), embeddings and vector search, NLP for text analysis, and forecasting. I deploy these as REST APIs with FastAPI and Docker, and I report findings to non-technical stakeholders.

I'm pursuing an MCA at Manipal University Online, alongside a BCA and an AI/ML certification from IIT Madras (via GUVI).
